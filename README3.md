# 천안시 청년정책 웹 프레젠테이션

원본 PPTX 10장의 텍스트·차트 수치·이미지·발표 노트를 변환했습니다. 정책 정보는 원본 조사 기준인 2026.11.06을 유지합니다. 웹 변환 과정에서 정책 사실을 추가하거나 재검증하지 않았습니다.

## GitHub Pages 게시
1. ZIP 압축을 풉니다.
2. `index.html`, `styles.css`, `app.js`, `assets/`, `.nojekyll`을 GitHub 저장소 루트에 함께 업로드합니다. 폴더 구조를 유지합니다.
3. 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
4. main 브랜치와 /(root)를 선택하고 Save를 누릅니다.
5. GitHub가 안내하는 Pages 주소에서 확인합니다.

빌드, 패키지 설치, 서버, 데이터베이스, API 키가 필요 없습니다. 이미지 경로는 상대경로여서 하위 저장소 주소에서도 작동합니다. 외부 스크립트·폰트·CDN 의존성이 없습니다. 출처 링크만 원문 사이트를 엽니다.

## 사용 방법
- 기본은 스크롤 모드입니다. 상단 발표 모드 버튼으로 한 장씩 볼 수 있습니다.
- 상단 구역 링크, 목차, 하단 점과 이전·다음 버튼으로 이동합니다.
- ← / →, PageUp / PageDown, Home / End 키로 이동합니다.
- F 키 또는 전체화면 버튼으로 전체화면을 전환합니다. 모바일 브라우저의 전체화면 지원은 기기별로 다릅니다.
- 모바일에서는 세로로 재배치하며 좌우 스와이프로 슬라이드를 이동합니다.
- 차트를 클릭하거나 키보드로 포커스하면 수치를 확인할 수 있습니다.
- 출처 버튼으로 현재 슬라이드의 원본 발표 노트와 링크를 확인합니다.
- 주소 끝의 #slide-8처럼 특정 슬라이드를 직접 열 수 있습니다.
- 시스템의 동작 줄이기 설정을 존중합니다.

## 파일
- index.html: 10장 전체 내용, 원본 발표 노트 및 출처
- styles.css: 원본 배색·비율 및 반응형 레이아웃
- app.js: 탐색, 전환, 차트, 전체화면, 목차, 발표 노트
- assets/: PPTX에 포함된 원본 이미지 2개
- .nojekyll: GitHub Pages 정적 파일 직접 제공

원본 슬라이드의 차트는 같은 수치를 사용하는 웹 차트로 재구성했습니다. PC에서는 16:9 구성을 유지하며 모바일에서는 가독성을 위해 세로로 재배치합니다. 글꼴은 운영체제의 한글 글꼴을 사용합니다.
